How a building is scored

NOT FOUND, never guessed

A fact is shown only when a source states it. Anything no source states is written NOT FOUND (highlighted amber) instead of being estimated: a missing buyer, unit count, city or link stays NOT FOUND until a source names it. Inferred facts (a parent company matched by brand, a state deduced from a city) are labelled as inferred.
